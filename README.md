# NetVision — Visualização e Análise de Dados de Rede

## Objetivo
O **NetVision** é um projeto integrador desenvolvido para a disciplina de Estrutura de Dados II. Seu principal objetivo é construir um pipeline de dados capaz de coletar, processar e estruturar medições contínuas de rede em janelas de amostragem, extraindo diretamente o vetor métrico fundamental:

X = [latência, perda de pacotes, jitter]

A partir desse vetor métrico, o sistema permite realizar a análise, monitoramento e apoio ao treinamento de modelos para identificação e prevenção de falhas em infraestruturas de rede.

---

## Descrição do Projeto
O projeto utiliza a infraestrutura global da **API do RIPE Atlas** como fonte ativa de dados em tempo real. Através da criação e consulta de medições customizadas (como testes de ICMP ping distribuídos geograficamente), realiza o tratamento e a agregações temporais, e constrói métricas precisas e auditáveis de desempenho de rede.
